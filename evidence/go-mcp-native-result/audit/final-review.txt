single assignment at go/mcp/client.go:449 retains the exact original pointer
in the shared converter. Every successful wrapper-result return path uses
that converter, including free calls, non-payment tool errors, automatic and
explicit payments, recovery fallback and terminal retry, and the existing v1
compatibility path. Recovery returns retryResult, not its earlier challenge.

The prior text projection, IsError, PaymentMade and settlement extraction are
unchanged. Hook projections and the unrelated shared hook/server converter
are unchanged. No signing, selection, payment-retry policy or transport logic
was modified. The existing CallPaidTool implementation already preserves the
SDK pointer and was correctly left alone. No dependency, custom schema,
marshaller or deep-copy implementation was added. No legacy/v1 source was
edited; the existing v1 tests remain in the complete MCP package test runs.

The README explains native content access and shared mutable ownership. The
short field comment and Fixed changelog fragment match the patch's scope.

ACCEPTED API / OWNERSHIP LIMITS

This is an additive API change, not universal Go source or JSON compatibility.
External unkeyed struct literals and complete-struct formatting/reflection/JSON
expectations can change. The untagged exported field intentionally emits the
outer RawResult key and native SDK inner JSON keys; it duplicates native data
and receipt metadata alongside existing projections. Nil emits null. Large
native media increases serialization size, and locally supplied unsupported
Go values in StructuredContent/Meta can now cause whole-wrapper JSON marshaling
to fail rather than being discarded. These are the approved design tradeoffs.

RawResult is the original borrowed mutable pointer, not a snapshot. Mutation
can diverge from the wrapper's copied text/flags/extracted receipt. Existing
hooks already share some nested metadata/structured-content data; this patch
does not newly isolate or broaden hook behavior. No immutability or transport-
pristine guarantee should be made. The scratch ownership test confirms this.
